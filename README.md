# To-Do List App ✅

A simple **To-Do List application** built with **HTML, CSS, and JavaScript**.  
You can add, mark complete, and delete tasks.  

---

## 🚀 Features
- Add new tasks  
- Mark tasks as complete (click on task)  
- Delete tasks  
- Responsive design  

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla JS)**
